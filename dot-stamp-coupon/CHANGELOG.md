# 변경 기록

## v1.2.0
- **미니게임 점수 보상**: 2,500점부터 500점마다 한 번씩 랜덤 추첨 → 당첨 시 등급별 쿠폰 발급 + 획득 이펙트 팝업
  - 당첨 확률: 2,500점 15% → 500점마다 +5%p (최대 60%), 점수가 높을수록 높은 등급 비중 증가
  - 등급: 노멀 / 레어 / 에픽 / 레전드 (`GameRewards` 시트에서 보상 수정 가능)
  - 같은 판에서 같은 점수 구간은 한 번만 추첨, 하루 최대 3개 (`GAME_DROP_DAILY_LIMIT`)
  - HUD에 다음 추첨 점수 표시, `?` 버튼으로 확률표 확인
- **게임 시작 안내 팝업**: "2,500점을 넘기면 특별한 선물이...?" 같은 의미심장한 문구 (4종 랜덤)
- **관리자 기간 일괄 도장 부여**: 시작일~종료일, 토·일 제외 옵션, 이미 승인된 날은 유지 (최대 93일)
- **글자 잘림 수정**: 한글 단어 중간 줄바꿈 방지(keep-all), 버튼/탭 줄바꿈 방지, 쿠폰 카드 배치 변경, 브라우저 글자 크기 자동 확대 방지. 글자 크기 1.6배 설정에서도 잘림 없음
- 팝업이 열려 있으면 게임 자동 일시정지
- 로그인 화면에 버전 표시
